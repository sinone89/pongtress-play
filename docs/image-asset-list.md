# PONGTRESS 이미지 리소스 리스트

현재 상태 = 이미 반영 / 이모지 / 캔버스 도형(코드로 그림).

## ✨ 5. 이펙트(FX) — 선택 (현재 절차적 글로우로 렌더, 넣으면 자동 교체)
`assets/fx/<name>.png` · **투명 배경, 위쪽(↑)을 향하도록** 그림 — 코드가 발사 방향으로 회전시킴.
로더(`FxArt`) 이미 배선됨. 파일이 없으면 코드가 그린 글로우 포탄/플래시로 폴백.
| 파일 | 용도 | 권장 규격 | 현재 폴백 |
|---|---|---|---|
| shell | 포탄(발사체 헤드) | 128×128 | 흰 코어 + 색상 글로우 오브 |
| muzzle | 총구 발사 플래시 | 128×128 | 방사형 버스트 + 스파이크 |
| boom | 명중 폭발(선택) | 256×256 | 화염구+충격링+파편(절차적, 충분) |
> shell·muzzle 2개만 넣어도 발사 연출 퀄이 크게 올라감. boom은 현행 절차적으로도 충분.

## 우선순위 요약
1. **적 6 + 보스 3 (9개)** — 전투·홈 연출 체감 가장 큼. 규격 256/512, 정면 포즈.
2. UI 아이콘(재화4·클래스3·내비5 = 12개) — 통일감.
3. 페그·배경·로고 — 선택(현행으로도 충분).

## 연동 메모
- 캐릭터는 로더(`CharArt`)가 이미 있음. **적/페그/UI 아이콘**은 넣어주면 로더 배선(캐릭터와 동일 방식, 없으면 현행 폴백)만 하면 자동 반영 — 파일만 규격대로 주면 됨.
- 프롬프트가 필요하면 `docs/char-art-prompts.md`와 같은 포맷으로 적/보스용도 만들어 줄 수 있음.
